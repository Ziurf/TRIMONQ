# TRIMONQ — site institucional

Site estático pronto para publicar gratuitamente no GitHub Pages.

## Antes de publicar

1. O e-mail oficial configurado é `trimonq@gmail.com`.
2. Se quiser, substitua o texto de "Projetos" quando houver jogos públicos.
3. Não declare no site recursos, coleta de dados ou políticas que não correspondam ao app publicado.

## Como publicar no GitHub Pages

1. Crie um repositório no GitHub, por exemplo: `trimonq-site`.
2. Envie todos os arquivos desta pasta para a raiz do repositório.
3. No GitHub, abra **Settings > Pages**.
4. Em **Build and deployment**, escolha **Deploy from a branch**.
5. Selecione a branch `main` e a pasta `/ (root)`.
6. Salve.
7. O GitHub exibirá a URL pública do site após o deploy.

## Estrutura

- `index.html` — site institucional
- `privacy.html` — política geral de privacidade
- `styles.css` — identidade visual
- `assets/trimonq-logo.png` — logo

## Para o Google Play

Use uma URL pública estável e mantenha:
- nome do desenvolvedor/estúdio;
- e-mail de contato;
- informações sobre o estúdio;
- política de privacidade acessível publicamente.

O conteúdo legal da política precisa ser revisado quando o primeiro jogo/app estiver definido.
